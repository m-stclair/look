# Film/process look presets

This bundle adds color/process-inspired presets for Look. They are not exact stock emulations: this app is a point-transform LUT builder, so it can shape tone, saturation, hue-window chroma, and luma-based split tint, but it cannot add grain, halation, bloom, gate weave, diffusion, lens effects, or channel-mixing behavior.

## Importable bundle

Use `film-process-look-presets.look.json` with the app's `Import` button. It contains 24 presets.

## Built-in project patch

This zip also patches `src/look-presets.js` so the same presets appear as built-ins.
